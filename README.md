# Mawlid Celebration Portal 1446 AH

A complete, responsive web application for a Mawlid (Prophet's Birthday) Celebration Event platform built with a modern minimalist "Plain White" theme, subtle emerald green and soft gold accents, dynamic client-side SPA routing, and local state persistence.

## 🎨 Theme & Design System
- **Minimalist "Plain White" Aesthetic**: Pure white background (`#FFFFFF`), light gray card containers (`#F8F9FA`), crisp dark charcoal typography (`#111827`), and emerald green (`#059669`) / warm gold (`#D97706`) accents.
- **Modern Typography**: Google Fonts (`Plus Jakarta Sans`, `Cinzel`, and `Amiri` for Arabic calligraphy).
- **Zero-Dependency Audio**: Interactive synthesized sound effects using the Web Audio API.

## 📄 Key Features
1. **Home Landing**: Hero section with countdown timer to Mawlid, live KPI stats strip, Prophetic Hadith wisdom card, timetable, and featured dispatches.
2. **Gallery**: Photo grid with category filters (`Stage Programs`, `Exhibitions`, `Awards`), live badges, search, and a full-featured Lightbox modal.
3. **News & Press**: Announcements with thumbnails, date badges, reading time, search, and a "Read Full Story" reader modal.
4. **Student Academic Magazine**: Showcase of student research papers with author profiles, abstracts, category tags, `A+`/`A-` font zoom controls, and print/PDF support.
5. **Interactive Seerah Quiz & Scoreboard**: Step-by-step multiple choice questions, timer, animated progress, instant answer explanations, HTML5 Canvas-rendered Certificate of Recognition (PNG download), and real-time Leaderboard.
6. **Admin Dashboard (PIN: `1446`)**: Full CRUD management for Gallery, News, Magazine, and Quiz questions, plus JSON backup export/import and factory reset.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/abddeveloper-hub/shuhba-moulid.git
cd shuhba-moulid

# Start the server
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
